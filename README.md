# 상담용 자료

세무 상담에서 화면에 띄우거나 인쇄해서 사용하는 설명 자료입니다.

| 파일 | 설명 |
| --- | --- |
| [`docs/annual-tax-flow.html`](docs/annual-tax-flow.html) | 연간 세무 흐름도 — 부가가치세 → 종합소득세 → 건강보험료 |
| [`docs/nonprofit-corp-tax.html`](docs/nonprofit-corp-tax.html) | 비영리 사단법인 세무 실무 노트 — 학술단체 기준, 법인세·공익법인 두 트랙 |

> 이 저장소는 현재 **공개(Public)** 입니다. 거래처명·법인명·금액 등 식별정보는 올리지 마십시오.

## 연간 세무 흐름도

**개인사업자 기준**입니다. 부가세는 일반과세자의 확정신고 연 2회(7.25 · 익년 1.25)를 기준으로 적었고,
법인사업자의 3월 법인세 신고는 개인 흐름과 섞이지 않도록 타임라인에 회색 점선 표기로만 넣었습니다.

브라우저로 파일을 열면 바로 보입니다. 별도 설치나 인터넷 연결 없이 동작합니다(웹폰트만 온라인에서 받아오며, 없으면 시스템 글꼴로 대체됩니다).

- **글자 크기** — 우측 상단에서 `기본 / 크게 / 아주 크게` 선택. 선택값은 브라우저에 저장됩니다.
- **인쇄** — `인쇄` 버튼. A4 가로로 맞춰져 있고 조작 버튼은 인쇄물에서 빠집니다.
- 화면 밝기 설정(라이트/다크)에 따라 색이 자동으로 바뀝니다.

내용을 고칠 때는 `docs/annual-tax-flow.html` 안의 `<svg>` 블록을 열면 항목이 주석으로 구분되어 있습니다.

## 비영리 사단법인 세무 실무 노트

**학술단체(학회 · 포럼) · 12월 결산 기준**입니다. 조작 방법(글자 크기 · 인쇄)은 위 흐름도와 같습니다.

법인세 트랙(법인세법)과 공익법인 트랙(상속세및증여세법)이 별개로 굴러간다는 점을 판정 도표로 먼저 보여주고,
학술단체 수입 항목을 법인세 · 부가세 두 기준으로 나눠 판정한 표를 붙였습니다.
핵심은 **부가세 면세와 법인세 비수익사업이 다르다**는 것으로, 학술대회 참가비 · 게재료 · 광고료가
면세이면서 동시에 수익사업에 해당합니다.

작업 이력은 [`docs/nonprofit-corp-tax_codehistory.txt`](docs/nonprofit-corp-tax_codehistory.txt)에 있습니다.
