## 연간 세무 흐름도

**개인사업자 기준**입니다. 부가세는 일반과세자의 확정신고 연 2회(7.25 · 익년 1.25)를 기준으로 적었고,
법인사업자의 3월 법인세 신고는 개인 흐름과 섞이지 않도록 타임라인에 회색 점선 표기로만 넣었습니다.

브라우저로 파일을 열면 바로 보입니다. 별도 설치나 인터넷 연결 없이 동작합니다(웹폰트만 온라인에서 받아오며, 없으면 시스템 글꼴로 대체됩니다).

- **글자 크기** — 우측 상단에서 `기본 / 크게 / 아주 크게` 선택. 선택값은 브라우저에 저장됩니다.
- **인쇄** — `인쇄` 버튼. A4 가로로 맞춰져 있고 조작 버튼은 인쇄물에서 빠집니다.
- 화면 밝기 설정(라이트/다크)에 따라 색이 자동으로 바뀝니다.

내용을 고칠 때는 `docs/annual-tax-flow.html` 안의 `<svg>` 블록을 열면 항목이 주석으로 구분되어 있습니다.

## 골프 스윙 진단서

**스코어 80~85 · 드라이버 평균 215 · 아이언 정타 불량** 조건으로 작성한 진단·훈련 자료입니다.
아이언 정타와 드라이버 비거리를 하나의 원인(임팩트 재현성)으로 묶어 추적하는 구성입니다.

브라우저로 열면 바로 보입니다. 13개 도해가 전부 인라인 SVG라 별도 이미지 파일이 없고,
인터넷 없이도 동작합니다(웹폰트만 온라인에서 받아오며, 없으면 시스템 글꼴로 대체됩니다).
화면 밝기 설정(라이트/다크)에 따라 색이 자동으로 바뀝니다.

- **셀프 진단** — 페이스 임팩트 9분할 맵 / 디봇 4패턴 / 구질 매트릭스 → 종합 판정표
- **기준선 도해** — P1·P4·P6·P7 각 구간에서 본인 영상에 그어야 할 선
- **드릴 6종 + 4주 프로그램**, 연습장 체크카드

> 이 자료는 **실제 스윙 영상 없이** 작성했습니다(로컬 드라이브에 접근할 수 없는 환경이었습니다).
> 영상을 확보하면 `docs/golf-swing-report_codehistory.txt`의 *다음단계*에 따라 기준선을
> 실제 프레임에 겹쳐 갱신하면 됩니다.

수치의 근거와 렌더 검증 이력은 `docs/golf-swing-report_codehistory.txt`에 있습니다.

## 골프 스윙 계측 기록부 (엑셀)

스윙 계측을 **일자별 탭**으로 쌓고 **누적관리 탭**이 자동으로 모으는 워크북입니다.

- **누적관리** — A열에 날짜 탭 이름만 입력하면 나머지 칸이 자동으로 채워집니다. 목표선과 추세 그래프 포함
- **연습일지** — 연습장 갈 때마다 한 줄. 센터히트 평균이 누적관리로 자동 집계됩니다
- **_템플릿_날짜탭** — 새 계측일이 생기면 이 탭을 복사해서 씁니다

날짜 탭의 셀 배치는 누적관리가 고정 주소로 참조하므로 **임의로 바꾸면 연결이 끊깁니다.**
참조 주소와 검증 이력은 `docs/골프스윙_계측기록_codehistory.txt`에 있습니다.
