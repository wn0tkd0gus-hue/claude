■ 사용코드 / 기술 사항
  - 단일 HTML. 라이브러리 없음. 도해는 전부 손으로 작성한 인라인 SVG.
  - 웹폰트: Google Fonts — Gothic A1(디스플레이) / IBM Plex Sans KR(본문)
            / IBM Plex Mono(수치). 미로드 시 시스템 글꼴로 대체.
  - 색 토큰: :root 에 라이트 팔레트 전량 정의 →
            @media (prefers-color-scheme:dark) :root:not([data-theme="light"]) 및
            :root[data-theme="dark"] 에서 토큰만 재정의 (3-상태 대응).
            의미색 고정: fault=결함(붉은색) / good=정답(초록) / accent=기준선.
  - SVG 는 CSS 클래스로 스타일 (.s-line/.s-fault/.s-good/.t-k 등).
    SVG 내부 <style> 미사용 — 아티팩트 제약 및 테마 토큰 상속 때문.
  - marker(화살촉) id 는 도해별로 유일하게 부여 (a1, a2, a4, a5, a6 …).
  - 표·도해는 .figscroll / .tw 로 감싸 가로 스크롤 처리 (본문 가로 스크롤 없음).
