■ 작업요약
  스윙 계측을 일자별로 누적 관리하는 워크북 신규 작성.
  요청 구조: "일자 기록은 탭으로, 누적관리 탭은 따로".

■ 시트 구성 (5개)
  1. 안내            사용법 · 새 계측일 추가 3단계 · 색 규칙 · 핵심지표 설명
  2. 누적관리        날짜 탭들의 핵심 수치를 자동 수집(A열에 탭 이름만 입력)
                     + 목표선 블록 + 머리하강 추세 꺾은선 그래프
  3. 2026-09-06      실제 영상 계측 기록 (스윙 3회 원자료)
  4. 연습일지        연습 세션 1행씩 누적 (60행 서식 준비, 4행은 작성 예시)
  5. _템플릿_날짜탭  새 계측일용 빈 서식 (복사해서 사용)

■ 자동 수집 방식 (핵심 설계)
  누적관리 B6:I6 이하 각 행:
    =IF($A6="","",IFERROR(INDIRECT("'"&$A6&"'!E15"),""))
  A열에 날짜 탭 이름을 입력하면 해당 시트의 고정 셀에서 값을 끌어온다.
  탭 이름이 틀리면 IFERROR 가 공백 처리하고, J열 종합판정이
  "※ A열 탭 이름을 확인하세요 (해당 시트 없음)" 를 표시한다.

  ※ 이 방식 때문에 날짜 탭의 셀 배치를 바꾸면 안 된다. 참조 고정 주소:
     B5=클럽 / E11=백스윙평균 / E12=다운스윙평균 / E13=템포비평균
     E15=머리하강@임팩트평균 / E16=최저점평균 / E18=왼무릎@임팩트평균
     E19=무릎변화평균
     템플릿을 수정할 일이 있으면 누적관리의 참조 주소도 같이 고칠 것.

  목표값은 누적관리 B30(0.01) / B31(0) / B32(0) 에 숫자로 두고
  J열 종합판정이 $B$30~$B$32 를 절대참조한다. 목표를 바꾸려면 이 세 칸만 수정.

■ 사용코드
  생성 스크립트: openpyxl. 폰트 맑은 고딕 10pt.
  색 규칙 — 파랑(0000FF)=직접입력 / 검정=수식 / 초록(008000)=타시트참조
            노랑배경(FFF6D5)=입력칸
  wb.calculation.fullCalcOnLoad = True 로 설정 → Excel 이 열 때 전체 재계산.
  (openpyxl 은 수식의 캐시값을 쓰지 않으므로 이 플래그가 없으면 일부 뷰어에서
   빈칸으로 보인다. Excel 본체는 이 플래그로 정상 표시됨.)

■ 검증 (중요 — LibreOffice 사용 불가 상태였음)
  이 세션에서 mediapipe 를 돌리려고 apt-get install libegl1 libgles2 를 실행했고,
  그때 mesa 패키지가 25.2.8-0ubuntu0.24.04.1 → .2 로 자동 업그레이드되면서
  LibreOffice headless 가 exit 81 로 죽게 됐다(최소 파일도 변환 실패).
  구버전 mesa 는 저장소에서 내려가 다운그레이드도 불가.
  → 표준 recalc.py 검증 경로를 쓸 수 없어 아래 방식으로 대체 검증했다.

  대체 검증: pip install formulas (파이썬 Excel 수식 엔진)
    formulas 는 INDIRECT 를 지원하지 않으므로, 검증본을 따로 만들어
    INDIRECT 160개를 직접 참조("'2026-09-06'!E15")로 치환한 뒤 전체 계산.
    치환 스크립트는 정규식 r'INDIRECT\("\'"&\$A(\d+)&"\'!([A-Z]+\d+)"\)' 사용.

  검증 결과 (전부 기대값과 일치):
    날짜탭  E11=0.9233  E12=0.2333  E13=4.1722  E15=0.038667
            E16=133.33  E18=141.33  E19=-21.333
            G13=미달 G14=합격 G15=미달 G16=미달 G19=미달 G20=합격
    누적관리 B6="드라이버 (또는 우드)"  C6=0.9233  F6=0.038667  G6=133.33
            I6=-21.333  J6="교정 중 — 아래 목표선과 비교"
            C30=0.038667  C31=133.33  C32=-21.333  C33=1  C34=0  C35=(공백)
            J7=(공백)  ← 빈 행이 조용히 비는지 확인
  미검증으로 남은 것: INDIRECT 의 문자열→참조 해석 자체(Excel 표준 동작이며
  치환본으로 참조 대상 셀이 옳음은 확인함). 파일을 처음 열었을 때 누적관리
  6행 B열에 클럽명이 뜨는지만 보면 즉시 확인된다.
